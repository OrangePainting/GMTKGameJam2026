# Ghost Boy Advance!
**A puzzle game where you try to save your roommate before it's too late!**
Playable in web [here](https://orangepainting.itch.io/ghost-boy-advance)

**Description:**
- Click on various items around the room to help your roommate escape
- There is a clock in the top left, and if daybreak arrives you lose!
- Mobile Friendly
- Made in 3 days for [GMTK Game Jam 2026](https://itch.io/jam/gmtk-jam-2026) and Hack Club's [Stardance](https://stardance.hackclub.com/home)
- Have Fun!

**Software Used:**
- Project made entirely within the free and open-source [Godot Game Engine](https://godotengine.org/)
- Sprites made using **Aseprite**, a pixel art creator
